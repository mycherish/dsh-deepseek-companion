日期：2026-11-08。状态：**已实施，阶段审核通过，本次原子提交收口**。执行入口：[first-release.md](first-release.md)。下方保留修改前截图审查；实施与验收记录见文末。Host 恢复逻辑和运行依赖保持原有边界。

## 目标与选择

推荐采用 **DSH 原生风格收口**：保留现有三窗口结构、Host 状态和宽度所有权，统一主题、字体、控件与状态层级，以少量 CSS 过渡提升响应感。先修复 Pop-out 的样式继承，再优化输入区和细节。

另一可选方向是重新组织消息区与工具栏，把更多操作移入菜单；同样需要修复主题继承，但会改变操作路径、扩大键盘和窄屏回归范围。首版优先采用前者，菜单调整仅限现有历史菜单，不新增复杂导航。

## 推荐实现规格

### 主题与字体基础

- 优先核实固定新旧宿主的公开主题 / 字体能力，再实现可 dispose 的共享样式桥接。使用宿主语义 token、文本与代码字体、字号设置；仅在旧版缺失时提供回退。
- Pop-out 打开时完整初始化，打开后跟随 light / dark / system 及字体、字号变化；处理关闭、重开和插件 dispose，取消订阅与监听。
- 基础样式限定在插件根节点及其独立窗口，统一 box sizing、字体继承和按钮 / 输入基础规则，不改变宿主全局样式，不依赖私有状态或复制整个宿主页面。

### 布局与控件

- 保留 44 px 标题栏和现有窗口尺寸规则；标题、关闭、切换窗口图标统一使用项目可用的图标能力。图标按钮建议 28 px 视觉尺寸、至少 32 px 点击区域，并提供可访问名称、提示和清楚的焦点。
- 输入区为主视觉锚点：统一一个输入容器，图片入口、文本输入和发送 / Stop 对齐；主操作清楚可辨。Deep Think / Search 保持可见和可辨识的选中状态；历史 / 新建降低常驻边框密度但保留文字入口。
- 窄屏允许工具栏换行，输入不能被工具按钮挤出；长链接换行，长代码在代码块内部滚动。保留 rightbar 的宽度所有权、Float 拖动 / resize 和单实例窗口语义。
- 消息采用统一间距、行高和宿主字体，用户消息弱背景、助手正文保持开放排版；代码使用宿主代码字体。历史菜单统一选中、悬停、键盘焦点与空状态。

### 状态、键盘与轻动效

- 普通连接状态保持安静；断流、恢复、删除及证据不足在输入区附近使用一处明确提示，操作只使用现有公开能力，不新增自动重发或解除写门控的路径。
- 逐项验收首次登录、空会话、流式 / Stop、上传、断流、恢复中 / 成功、删除确认、证据不足、错误 / 重试。面向用户的提示提供下一步，诊断信息不直接堆叠在主界面。
- 保持 Tab 顺序、可见 focus、菜单键盘操作与 Esc 关闭；中文输入组合期间 Enter 不误发送。禁用操作同时有视觉与语义状态。

| 对象                | 建议动效                                 | 减少动态效果 |
| ------------------- | ---------------------------------------- | ------------ |
| 按钮悬停 / 按下     | 120 ms 背景 / 颜色过渡                   | 立即切换     |
| 页内窗口与历史菜单  | 140–160 ms opacity，必要时小幅 transform | 立即显隐     |
| 思考折叠 / 状态替换 | 120–160 ms 淡入；保证内容与焦点稳定      | 立即切换     |

不逐 token 动画，不自动拉回用户正在阅读的历史。优先 CSS 与现有组件；需要异步动画时支持取消并随关闭 / dispose 清理。原生 Pop-out 的出现不模拟操作系统窗口动画。

## 2026-11-08 实施记录

用户批准推荐方案后，在 `codex/fr3-ui-hardening` 实施 FR-3，尚未提交或发布。

- 新增可清理的 Pop-out 样式桥接：从主页面 body 读取公开解析后的颜色、文本 / 代码字体和字号 token，监听 html / body 呈现变化与系统偏好；关闭、重开、插件 dispose 均释放监听。无新增宿主主题服务依赖，不写宿主设置。
- 三窗口共享局部基础样式、SVG 标题栏按钮、32 px 点击区、悬停 / 按下 / focus-visible。输入区使用统一容器，主操作保留发送 / Stop，工具操作减少常驻边框；正文、标题、代码跟随宿主设置。
- 增加 120–160 ms CSS 淡入与颜色过渡，减少动态效果时直接切换。没有动画定时器、逐 token 动画或额外框架。
- 组合输入使用现代 `isComposing` 与 composition 事件，避免确认文字时误发，不使用已弃用的 `keyCode`。历史菜单绑定各自 ownerDocument，方向键仅在触发按钮 / 列表内导航；Esc 及外部点击关闭，加载中也可关闭并返回焦点。新回复仅在接近底部时跟随，切换会话重新跟随。
- 页面调用栈在用户界面转换成检查 DeepSeek 网页后重试的提示；业务拒绝原因继续显示。不改变错误解除身份判定或恢复写门控。
- 新增 `pnpm test:ui`：以实际组件与本地合成 Host HTTP / SSE 协议测试渲染、焦点、状态及窗口清理。需已有匹配 Chromium；Browser plugin not available，使用仓库 Playwright。它不访问真实 DeepSeek，也不代替真机恢复验收。
